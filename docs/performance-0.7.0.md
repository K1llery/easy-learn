# 0.7.0 阅读速度改进与实测

日期：2026-09-22。主要使用场景：中文学习者阅读英文技术文档、编程教程。

## 已完成

- 官方 `deepseek-flash`、`deepseek-v4-flash`、`deepseek-chat` 显式使用非思考模式；参数仅作用于官方域名。其他未知模型保持服务商原行为。
- 自动注释每批最多 4 个候选；短注释回答中文名和当前作用，缩写包含全称。
- SSE 按完整候选增量解析，经候选 ID 对应检查后，通过扩展专用连接逐条显示。支持 UTF-8/事件跨网络分片，不显示未闭合 JSON。普通 JSON 返回仍可兼容。
- 当前屏幕、后两屏、其余前方正文、已读正文依次优先。每次派发新批次重新读取位置；在途请求不因滚动反复取消。全文仍会继续预载。
- 主动解释和翻译优先于尚未开始的后台任务；全局并发仍为 2，不抢断已经付费的请求。
- 首次有效输出 25 秒、输出停滞 12 秒、单个流总时长 60 秒；心跳不延长有效输出等待。中断保留已验证条目，不自动付费修复或重试。
- 默认在本机缓存最多 500 条术语/缩写释义、保留 30 天，总序列化大小最多 500,000 字符。语境只作为 SHA-256 缓存键输入，不以明文保存在缓存键中。缓存结果仍可能包含原文短语。整段正文、代码、命令和问答不持久缓存。
- 缓存区分模型、接口、领域、熟悉程度、标题、章节与具体语境；候选临时 ID 不影响命中。设置提供关闭/清除入口；清除后在途旧请求不能重新写回缓存。
- 显示当前屏幕已准备比例；耗时、批次、tokens、缓存命中放在折叠详情。
- 修复词典误判：相邻段落中的其他缩写定义，不再让当前 API 等常用词失去本地释义。

保留：悬停不请求模型、解释预先准备、命令不受默认关闭的代码注释开关影响。

只发送人工编写的公开技术概念片段，包括 lifespan、backpressure、ASGI、dependency override、connection pool、DR、fixture、idempotency key。官方 `https://api.deepseek.com/chat/completions`，`deepseek-flash`。密钥通过不回显的终端输入进入临时进程，未写入文件、浏览器配置或 Git。没有并发压测，没有自动重试。

合计 8 次请求，7 次成功；成功响应提供的用量合计 **6,366 tokens**。原模式复测中，1,207 个输出 tokens 含 **948 个 reasoning tokens**。失败请求没有 usage，无法确认其实际计费；以服务商账单为准。没有继续调用该测试密钥。

新版适配器复测通过一个临时、本机回环中继调用官方服务，中继只补入内存中的密钥并转发字节；实际提示词、请求参数、SSE 解析、候选校验、增量回调均运行项目生产代码。四条均对应到原候选，未缺失、未截断；ASGI 全称得到保留。人工抽查看不到明显释义错误，但这不是全面的语义准确率评测。

限制：样本少、顺序执行、上下文缓存命中比例不同，部分测试的批次数量和输出协议不同。因此不能把这些数字表述为普遍提升某个倍数，也不能据此给出 P95。4 个候选是当前暂定折中，并非已证明最优。原模式一次连接失败不能归因于插件或思考模式。

官方依据：[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[模型与计费](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。文档注明 Flash 默认开启思考，并支持显式关闭；运行时复测也返回了 reasoning 用量。

## 本地验证与后续计划

- 单元测试覆盖增量回调、跨字节分片、未完成 JSON、重复/伪造 ID、中断保留、主动取消、心跳超时、优先队列、上下文隔离、缓存并发写入/清除/过期/上限。
- 浏览器使用真实 Chromium 扩展和本地模拟接口，覆盖整页预载、流式首条先出现、跨刷新缓存、缓存清除、跳章节优先、原文保持、词典即时显示和悬停零请求。浏览器回归不使用真实密钥。
- 正常运行 `pnpm test`、`pnpm build`；Linux 浏览器运行 `PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm test:e2e`。此工作区原有 macOS 浏览器路径不适用于 WSL，使用官方 Linux Chromium 缓存，不修改全局网络配置。
- 后续使用真实阅读反馈检查“读到术语时尚未准备好”的频率；当前屏幕准备比例提供即时参考。当前优先级仍按位置，不追踪个人阅读历史、不上传遥测。
- 自适应提前距离、额外并发、跨语境概念复用、更多领域词典仍需证据后再调整；本轮没有把不确定释义跨页面强行合并。
