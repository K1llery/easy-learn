# 0.14.2：PDF 阅读控制与缩写全称

2026-10-01。补齐独立工作台与扩展工作台的 PDF 原版阅读控制，保留既有逻辑目录、图表、文字选择和预载释义。

## 使用与行为

- 默认开启连续阅读，可直接滚动跨页；取消勾选后按单页阅读。滚动会更新当前物理页和伴读范围，逻辑章节目录继续独立定位。
- 缩放提供“实际大小”“适合页面”“适合宽度”。默认适合宽度；实际大小是 PDF.js 的 100%，按 PDF 点与 CSS 像素的换算显示，不承诺屏幕上的物理厘米一致。
- 滑条支持 25%–400%，调整后显示自定义比例。适合模式随阅读视口尺寸变化重算；大比例可在阅读区域内横向滚动，不撑破整个页面。
- 输入第几页后点击“跳转”或按 Enter，直接定位该物理页；输入时不移动正文。非整数、空值、零或超出页数会显示可用范围。上一页 / 下一页和连续滚动会同步页码。
- 缩写候选与普通生词分开筛选，LLM、TEE 等短缩写不再被普通单词的长度 / 全大写规则剔除。英文全称来自现有模型 `expansion` 字段，显示于提示、释义面板和生词本；Anki TSV 保持原有四列，全称、说明和歧义提示一起进入第三列。
- 提示模型结合上下文给英文全称与中文含义。不确定时保留歧义；没有全称的结果明确提示缺少信息，不在本机硬猜缩写。已有缩写注释缓存使用新契约标识，普通词汇缓存和生词记录继续保留。

导入、缩放、跳页和悬停均不开始模型分析；开启伴读仍需用户主动操作。已收集而缺少全称的旧生词记录不会凭空补写。扫描 PDF 的查看能力保留，新增 OCR 不属于本轮范围。

## 复用与实施中确认的问题

直接使用已安装的 **PDF.js 6.3.289** `PDFViewer`、事件总线及匹配样式，未新增 PDF 阅读依赖或实现另一个页栈 / 渲染队列。viewer 负责连续页面占位、可见页调度、画布缓存和缩放。接入依据：[官方组件示例](https://github.com/mozilla/pdf.js/blob/master/examples/components/simpleviewer.mjs)、[页面与缩放选项](https://github.com/mozilla/pdf.js/wiki/Viewer-options)；检查了[适合宽度尺寸反馈 #12118](https://github.com/mozilla/pdf.js/issues/12118)。这些反馈用于构造检查场景，不代表旧 issue 的成因必然适用于当前版本。

PDF.js 为 Apache-2.0；沿用已打包的许可文件，viewer 样式和相关资源由现有 Vite 构建处理。模型字段、候选识别和缓存继续使用共享模块。

| 确认的问题 | 处理方式 |
| --- | --- |
| viewer 模块读取全局 API，且要求有定位的滚动容器 | 先加载同版本 legacy API，再加载 legacy viewer；使用固定高度框架内的绝对定位容器 |
| 阅读中报告当前页，若被当成目录指令会重复跳回标题 | 显式 `PdfDestination` 与 `onPageChange` 分离；异步位置转换检查导航代次 |
| viewer 的 100% 与提取文字的 viewport scale 1 不同 | 使用原页 viewport 转换标题目标，交由 viewer 定位；保留用户缩放 |
| 连续阅读含多个画布，重导入前旧画布可能仍存在 | 按物理页定位断言，先等待新文档身份；使用库的取消与生命周期能力清理 |
| PDF.js 会对尺寸取整 | 布局断言容许合理的 CSS 像素取整误差；实际大小和比例另行验证 |
| 只改缩写提示词仍不能让阅读器展示全称 | 同时检查候选 kind、输出解析、展示、保存、导出与持久缓存 |

独立审查确认了一个保存链路问题：缩写的歧义提示原先会在收集与导出时丢失。已将 `ambiguity` 纳入生词记录、展示和原有四列导出，并增加保存后刷新与导出的浏览器回归；修复已通过独立复核，无新的重要发现。

可复用流程已更新在 `.agents/skills/reading-workbench-maintenance/`，项目入口与关键约束写入根 `AGENTS.md`；对应本机安装副本同步更新。具体运行证据留在此文，不写入永久规则。

## 验证

使用本机模拟 API、人工 PDF（真图片、同页子标题、跨页章节、缩写、24 页长文档），以及缓存中的公开 TraceMonkey 论文；不使用个人账户。检查图像像素、生词原文、按需画布、缩放尺寸、目录与页码跳转、手机窄屏、重导入和模型请求计数。

执行 `pnpm test`、`pnpm build`、`pnpm build:workbench`，浏览器命令为：

```sh
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm test:e2e
```

本轮结果：170 项单元测试、46 项完整浏览器回归通过，扩展与独立工作台生产构建通过。补充的缩放后缩写标注位置与悬停回归也通过。公开 TraceMonkey 文件共 14 页，直接跳转第 14 页后只有 4 个已渲染画布，模型分析请求为零，未出现浏览器脚本错误；这不等于已验证用户自己的论文。
