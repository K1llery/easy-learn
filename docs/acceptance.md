- 85 项单元测试、类型检查、生产构建及 16 项 Chromium 浏览器流程测试通过；所有模型请求走本机模拟 API，没有使用个人 API Key。

每篇结束后记录：

1. 关掉面板，用自己的话解释一个刚学到的概念。
2. 回答一道该概念的应用问题，注明是否仍需要查阅解释。

## 0.3.0：本地筛选、请求预算与滚动回归（2026-09-20）

在用户明确允许本地浏览器测试后，独立 Chromium 已正常启动；本轮未复现原先启动阶段的 macOS 崩溃。未修改系统设置或个人浏览器配置。

- 类型检查、生产构建、52 项 Vitest 测试及 6 项 Playwright 流程测试通过。
- 本地保守规则先筛选，普通词、常见标题、通用变量名、不含技术线索的未知大写词不进入模型；每段最多两个候选。陌生概念可能漏标，可划词解释。
- 自动分析最多八个候选一批，每个语境片段最多 420 字符；每次开启默认八批上限，明确点击继续才增加八批。主动翻译、问答和连接测试不计入自动预载预算。
- 40 个相同语境的重复段落在实际浏览器中只发起一次分析请求；滚到第 36 个术语仍能悬停查看，未新增请求。不同语境不盲目复用缩写解释。
- 80 个不同候选自动处理八批后停止，点击继续后总计十批完成；普通词样本零请求、零标注。以上是模拟 API 实测次数，不是供应商费用估算。
- 实际浏览器覆盖嵌套滚动、动态正文、限流后手动恢复、悬停零请求、持续进度、编号文本响应及链接/原文保留。恢复部分有效结果的格式测试另由单元测试覆盖，格式错误不再自动调用模型修复。
- 参考材料包含用户提供的 FastAPI HTML、Python 官方 Classes 文档节选、FastAPI 官方 README 节选及 Attention Is All You Need 摘要。后三者的来源与抓取日期保存在 `tests/fixtures/references/*.json`。本地测试只给模拟接口发送文本。
- 已检查 `test-results/preloaded-hover.png` 的轻量下划线、预载弹窗与进度条布局。
- **保留限制：** 在当前测试 Chromium 中，嵌入面板滚动后自动化鼠标有时命中外层 iframe，未触发内部按钮。追问使用真实键盘 Enter 提交完成流程；没有据此认定鼠标兼容性已修复。Chrome / Edge 的人工鼠标回归、真实服务商输出质量及多人试用仍待完成。

## 0.4.0：整页预载、代码开关和隐藏注解（2026-09-20）

当前行为以本节为准，取代 0.3.0 的视口调度和八批停止线。

- 代码注释默认关闭，本机持久保存。命令行独立识别，即使和代码/注释混在同一个文本块，也不受代码开关影响。侧边悬浮设置和扩展设置同步；重新打开已有解释的代码不重复请求。
- 启用后立即扫描已加载的全文，附近候选优先，后续全文连续处理，不等待滚动。动态加载内容仍需进入 DOM 后才能发现。模型时间无法消除，未完成解释不标记，悬停不临时请求。
- 删除旧版八批自动停止限制，保留合批、相同语境复用和暂停/继续入口。处理全文可能增加 API 用量。测试中 80 个独立候选在 scrollY 始终为 0 时完成十批，包含最后一段。
- 使用浅金色背景和深金色实线下划线提高辨识度，保留原文节点及复制/链接行为。
- 网页侧边新增可折叠“伴读设置”，包含代码开关、学习领域、熟悉程度、暂停预载，以及模型设置/隐藏列表入口。密钥仍仅由可信扩展设置页访问。
- 悬停注解增加“我懂了，不再显示”，按领域与含义隐藏，设置页可恢复。旧版已掌握数据沿用，不把点击隐藏解释为知识检验或掌握结论。
- 已移除知识检验的页面入口及作答/反馈 UI；保留翻译与追问。
- 54 项单元测试、8 项真实 Chromium + 模拟 API 流程测试通过；包括代码默认关闭、开关持久化、命令行保留、未滚动全文预载、隐藏和恢复零额外请求。视觉检查包括侧边设置和增强后的高亮。
- 测试没有使用个人 API Key；真实供应商质量和此前记录的面板滚动后鼠标自动化兼容性仍不属于本轮已验证范围。

Git 从本轮开始启用，先记录当时包含未完成改动的工作区快照，再提交完成并验证的 0.4.0。未配置远程仓库。分发包：`artifacts/easy-learn-0.4.0.zip`。
