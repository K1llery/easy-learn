# Easy Learn · 读懂，再学会

面向中文技术学习者的 Chrome / Edge 扩展。网页伴读会提前准备术语、缩写、命令和代码解释；阅读原生 PDF 时，可选中文字后用右键菜单解释或翻译。保留原文的同时，支持选段快测、主动练习、应用任务和本地复习。产品方向与验证思路见 [从读懂到会用](docs/learning-direction.md)。

## 安装试用

1. 如果已经有本项目的 `dist` 文件夹，可直接安装。重新构建需要 Node.js 22.12+（或 24 LTS）与 pnpm：
   ```sh
   pnpm install --frozen-lockfile
   pnpm build
   ```
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选择本项目 **dist** 文件夹。
3. 在扩展详情中打开「扩展程序选项」，可从本机个人方案、中国大陆与海外 / 国际服务分组中选择预设，或填写 OpenAI 兼容接口。详细介绍与推荐理由见 [AI 服务商与模型选择](docs/model-providers.md)，免费额度见 [免费方案说明](docs/free-providers.md)。地址如 `https://你的服务商/v1`，插件会补上 `/chat/completions`；也接受已经包含该路径的地址。
4. 点击「保存并授权」，再点击「测试已保存的连接」。本机模型服务可用 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`；其他服务要求 HTTPS。
5. 打开英文技术文档或博客，点击工具栏里的 Easy Learn 图标即可开始网页伴读。原生 PDF 不支持整页伴读；选中文字后右键选择「用 Easy Learn 解释 / 翻译选中文字」，结果会显示在浏览器侧栏。

加载后建议将扩展固定到工具栏。浏览器内置页无法注入时，启动状态窗会提供重试、设置和独立的粘贴文本面板入口。更新构建后，在扩展管理页点击重新加载，再刷新已开启伴读的网页。

## 当前个人试用：ChatGPT Plus 本机代理

本机已通过 CLIProxyAPI 连接当前 ChatGPT Plus 账号的 Codex 通道。该预设使用 GPT-6 Luna；翻译采用无思考强度和精简输出，其他任务采用低思考强度。扩展设置里选择「ChatGPT Plus · 本机 CPA（个人使用）」，将 `.cache/cpa/extension-key` 中的访问密钥填入 API Key，保存授权并测试连接。更新扩展后，先在扩展管理页重新加载。此项是当前本机试用方案，不作为商店上架后的默认连接方式；不需要在扩展里填写 ChatGPT 密码。

代理可用 `python3 scripts/cpa-local.py status` 检查，用 `start` / `stop` 启停。换机首次准备时执行 `python3 scripts/cpa-local.py setup --auth-file <已登录 Codex 的 auth.json 路径> [--proxy-url <本机代理地址>]`，工具会下载并验证固定版本的 CPA，生成本机访问密钥，导入已有登录凭据并启动服务。凭据、密钥、程序和日志都放在 Git 忽略的 `.cache/cpa/`。更多兼容性和发布边界见 [Plus 接入记录](docs/chatgpt-plus-integration.md)。

## 新增：练会这一段（0.10.0）

1. 打开选段解释面板，点击「练会这一段」；也可粘贴文本后选择「先练再看」，先练再看解释。
2. 写下想把这段知识用在哪里（可选），点击「出一道练习题」。AI 根据当前选段出一道开放题，并准备一个应用小任务。
3. 先用自己的话回答，再点击「请 AI 找出理解缺口」。反馈区分理解正确的部分、具体缺口和参考解释；提交前不显示反馈或应用任务。练习中收起原文和解释，可随时返回阅读。
4. 试着完成应用小任务。点击「保存练习，明天复习」后，原文选段、目标、题目、回答、反馈与任务才保存在当前浏览器。
5. 从面板的「我的复习」或设置页的「打开我的复习」进入列表。复习时先回忆，再看第一次的 AI 反馈，自己选择「还需练习」或「能独立解释」。可在「记录实践」写下做法、结果和下一步，并导出 Markdown 学习记录。

成功生成练习和提交反馈通常各请求一次模型；进入练习页、保存、复习、记录实践和导出不请求模型。限流或失败保留输入，只在再次点击时重试。复习不自动评分，也不重新让 AI 判断回答；复习次数和实践记录数不等于掌握程度。

初次保存 24 小时后到期。自评能独立解释后，间隔依次为 3 / 7 / 14 / 30 天，最长 30 天；还需练习则回到 1 天。这是固定的复习建议，不是个性化记忆算法。到期后在「我的复习」显示，不发送系统通知。

## 新增：选段快测（0.11.0）

在普通网页中选中一段文字后，浮动工具条会直接显示「解释」「考考我！」和「翻译」。点击「考考我！」后，AI 根据所选文字出一道四选一题；在选择答案前不展示正确答案，选择后显示对错、参考答案和依据。再次选择「再出一道」会按需请求下一题。

快测请求仅发送主动选中的文字，不附带页面标题、相邻段落或整章；题目和作答不会保存到复习列表。选中 PDF 的操作仍使用浏览器原生右键菜单。面板将「解释」「练会这一段」「考考我！」并列显示，「我的复习」保留为顶层入口；应用任务仍在开放题作答并获得反馈后出现。

## 使用方式

- 当前页面每个概念的首次标注使用浅金色背景与实线下划线；同一含义后续出现时改用淡色点线，减少重复强调。悬停立即显示已经预载的短注释，不发起模型请求；原文和链接保持不变。
- 常见软件技术词和已支持的命令使用内置通用释义，即刻标注，零 API 请求。通用词典不强行消歧 DR 等缩写；需要上下文判断时再发送给模型。设置中的“离线模式”可完全停止新的 AI 请求。
- 本地规则先筛选明确的技术词和缩写；普通词、常见标题、通用变量名默认跳过。每段通常最多六个候选；可选的「扩展词汇」实验模式每段最多再加一个。HTTP 方法结合 Web 语境判断，避免标记普通 get/post 动词。漏掉的内容仍可划词解释。
- 开启后立即扫描整页，每批最多 4 个候选，携带各自最多 420 字符的语境片段；每批重新排序，优先当前屏幕、接下来两屏及后续正文，最后处理已读位置；两路并发自动处理全文，不以滚动为触发条件。同一语境复用缓存，动态加载的新正文自动补充。限流或认证失败时暂停，已有注释仍可阅读。
- 整页自动预载，不再设旧版八批停止线。右下角常驻浮窗显示进度，悬停约半秒展开注释类型、代码开关、偏好、暂停和错误详情。全文预载可能比仅处理视口消耗更多额度；主动翻译/追问/连接测试也会产生请求。实际费用由服务商定价决定。
- CLI 命令与代码注释各有开关；两者都在「01 · 注释类型」下，命令说明独立于默认关闭的代码注释。除常见 FastAPI 教程命令外，还会识别 `sed`、`grep`、`awk` 等常见 shell 工具。对 Linux、WSL 和 PowerShell 提示符会剥离提示符，仅把命令本身送去解释；带提示符的命令输出不会当代码分析。解释不执行命令。
- 代码注释默认关闭；在网页浮窗或扩展设置页的「01 · 注释类型」中开启。命令行类型开关独立生效。开启代码后按最多八行分块，预载逐行解释及组成片段。
- 网页中选中一段文字后，浮动工具条提供「解释」「考考我！」和「翻译」三个入口。快测只发送主动选中的文字，答案在作答前隐藏；原文不替换，也不添加包装节点。
- 原生 PDF 中选中文字后，右键选择「用 Easy Learn 解释选中文字」或「用 Easy Learn 翻译选中文字」，结果在侧栏显示。只有主动选中的文字和文档标题会发送给模型，不读取或上传整份 PDF；过长选区限制为 16,000 字符并明确提示。扫描版 PDF 无法自动识别，需先复制可识别的文字再粘贴。
- 悬停注释中的「深入理解 / 翻译」才会打开右侧面板并按需请求详细解释。预载注释与主动追问是两种不同操作。
- 「翻译这一段」保留原文；「加入当前章节」明确扩大模型输入范围；「继续追问」带上当前会话的最近对话。
- 悬停注解中点击“我懂了，不再显示”即可隐藏这一含义的注解，设置页的“不再显示”列表可恢复；以领域和概念含义区分，不混淆同一缩写的不同含义。此操作只是显示偏好，不评估掌握程度。
- 点击浏览器工具栏图标会立即尝试开启当前页面；状态窗会在成功后自动关闭，遇到无法注入的页面时提供重试和粘贴文本入口。右下角的常驻「阅读注释」浮窗提供进度、类型选择、暂停、粘贴文本和设置入口。鼠标悬停片刻后展开详细设置。

## 数据与权限

- 扩展使用 `activeTab`、`scripting`、`storage`、`contextMenus` 和 `sidePanel` 权限；不会预先读取网页或整份 PDF。模型地址作为可选权限，在保存配置的点击操作中申请。
- API Key 和偏好存在 `chrome.storage.local`，仅扩展可信界面与后台能访问；不使用同步存储。它不是操作系统保险库，不应把扩展配置目录交给他人。
- 自动预载发送页面标题和本地筛选候选的短语境；主动深入解释、翻译和开放式练习会发送章节标题、目标段落及相邻段落。网页快测只发送用户选中的文字。首次配置页明确说明发送行为和可能的费用。扩展本身不运行任何分析或遥测服务。
- 学习练习只在点击保存后写入 `chrome.storage.local`，最多 50 条且总量不超过 2 MB（UTF-8 JSON）。保存当前选段、标题、目标、题目、第一次回答与 AI 反馈、应用任务、最近一次回忆、实践记录和复习日期，不保存邻段、整章、网页地址或密钥。记录不自动过期，可逐条删除或从设置页清除全部本机数据；达到上限时拒绝新增，保留已有记录。导出的文件由用户自行保管。
- PDF 右键操作只把用户主动选中的文本与文档标题发给已配置的模型服务。选区暂存于 `chrome.storage.session`，侧栏读取后立即删除；关闭标签页也会清除未读取的选区。
- 默认单个段落最多 16,000 字符，相邻段落各最多 4,000 字符；主动扩大后章节最多 24,000 字符。超长段落不自动分析，可选取片段手动处理。
- 未主动保存的正文和问答仅驻留会话内存；关闭网页、停止伴读、重载页面或后台休眠会清除会话内容。默认在本机保存最多 500 条术语/缩写释义，30 天过期，并限制总大小；开启扩展词汇时也会缓存词汇解释。术语缓存不持久保存整段语境、命令或代码。释义本身可能含原文短语，语境仅以哈希参与缓存匹配。模型、领域、熟悉程度、标题与语境一致才复用；不按缩写字面跨语境复用。设置页可关闭并清除缓存，也可单独清除。模型供应商的日志保留方式由该供应商控制。
- 密钥不交给页面脚本，不写日志；模型文本按纯文本显示。网页和用户文本不会拼接进系统指令。仍需自行判断 AI 解释是否准确。
- 后台最多两个模型请求并发，自动预载两路并发执行；主动解释与翻译优先于排队中的预载，不打断在途请求。自动注释使用流式返回，完整条目验证后立即标注；服务商返回普通 JSON 时仍可读取。首次有效内容等待最多 25 秒，开始输出后连续 12 秒没有内容即中止，总时长最多 60 秒；其他操作仍为 25 秒。流式中断保留已完成条目，未完成项手动重试。兼容 JSON 围栏、简化字段、编号文本和部分有效结果；格式异常只在本地解析，不自动付费修复，未完成项由用户手动重试。
- 伴读开启期间，每 20 秒发送一次扩展内部消息维持后台连接，不调用模型、不产生 API 费用；关闭后停止。

## 开发与验证

```sh
pnpm check
pnpm test
pnpm build
# 使用项目内缓存，无需写入系统的浏览器缓存目录
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm exec playwright install chromium
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm test:e2e
```

单元测试检查正文过滤、上下文边界、原文锚点、缓存、并发及模型错误。端到端测试使用真实 Chromium 扩展与本机模拟模型 API，不发送真实文章给外部服务。测试专用扩展副本临时加入本机测试站点权限，用来程序化触发注入；生产 manifest 不含该权限。

- `src/core`：独立的文本接口、模型适配、校验和内存缓存。
- `src/background.ts`：权限边界、设置、模型调用与页面/面板通信。
- `src/content`：正文提取、全文预载、无损高亮和选择操作。
- `src/ui`：React 阅读面板与设置。
- `docs/acceptance.md`：真实模型和小范围试用验收表。

PDF 暂不支持整页自动标注、扫描版 OCR、图片/公式识别或整篇双语对照；只支持从浏览器原生阅读器选中文字后按需解释或翻译。图片、视频、跨域 iframe 和封闭式组件也不支持；终端只分析输入行，跳过日志、进度条和隐藏的重复代码。正文提取依赖常见 `article/main` 与段落结构；不适配的页面可以粘贴文本。语义判断、翻译准确性和学习效果需要真实模型与真实用户检验。

### 0.8.2：修复工具栏启动无反馈

### 0.8.1：一键开启、浮窗设置与候选过滤

点击浏览器工具栏图标会立即开启当前页，不再先选择再确认；页面右下角显示伴读浮窗，悬停片刻展开注释类型、代码开关、学习偏好和进度。流式响应会在每条解释完整到达时立即标注，不等整批或整页完成；文件路径、文件名、域名和网站链接名称会在候选筛选阶段排除。代码注释已移入「01 · 注释类型」，并保持默认关闭且与 CLI 独立。

单条模型解释的流式结果立即高亮，不等待整页或整批完成。候选筛选会在发请求前剔除文件路径、常见文件名、域名和作为链接显示的网站名称。命令行识别支持 Linux/WSL/PowerShell 提示符。扩展词汇仍默认关闭；词频近似表不等同官方 CET-4，启用可能增加用量。来源和许可见 `public/vocabulary/ATTRIBUTION.md`。
