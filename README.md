# Easy Learn · 读懂，再学会

支持多语言译文的外语阅读辅助工具，提供 Chrome / Edge 扩展与独立阅读工作台。网页伴读会提前准备生词、术语、缩写、命令和代码解释；工作台支持 PDF、EPUB、TXT、Markdown，保留原文并提供中文语境释义。既有 PDF 学习页和网页仍支持选段解释、快测、整页测验、主动练习与本地复习；支持 API Key 接入，也可用 ChatGPT / Claude 订阅账户在扩展内 OAuth 登录。产品方向与验证思路见 [从读懂到会用](docs/learning-direction.md)；适合计算机专业学生的源码阅读路线见 [项目架构拆解](docs/architecture-guide.md)。

## 网页全文双语翻译（0.16.0）

支持简体／繁体中文、英语、法语、日语、韩语等 **16 种译文语言**。在设置中保存默认语言，或在网页浮窗、选段学习、粘贴面板与 PDF 文本页的 **译文语言 / Translate to** 中临时选择。阿拉伯语支持从右向左展示；不同目标语言的缓存独立。输入语言处理保持现状，释义和测验仍使用中文。详细操作见 [多语言翻译](docs/multilingual-translation.md)。

点击扩展图标开启伴读，再点击右下角 **翻译全文**。所选语言的译文逐段显示在原文下方，保留原文、链接与代码；优先处理当前屏幕，动态新增正文自动补译。可随时暂停、继续或还原原文；同一页面还原后再次开启会复用已完成的译文。限流或失败后暂停，需主动继续，不自动付费重试。网页全文翻译会将识别出的正文分段发送给已连接的模型服务，使用该服务的额度。

默认 **6 路并发、每批 8 个生词候选**，可在设置中选择最高 **12 路**。全文翻译和注释共用后台总上限，主动解释和测验优先于排队任务；已保存的并发和批次设置会保留。并发提高整页吞吐，单次生成速度仍由上游决定。实现复用、开源项目 / issue 参考、许可边界与验证见 [全文翻译记录](docs/browser-translation-0.16.md)。更新后重新加载扩展并刷新文章页面。

## 大众试用与自动打包（0.15.0）

提供 Windows x64、Mac Apple 芯片、Mac Intel 三种独立软件包，以及 Chrome / Edge 插件包。桌面版内置运行环境，解压后双击应用即可启动本机后端并打开默认浏览器，无需安装 Node.js、pnpm 或 Docker，首次启动也不下载运行环境。再次打开复用同一服务；工作台里的“退出软件”结束服务。使用与数据保存说明见 [一键阅读版](docs/desktop-start.md)。

首次连接以“选择服务 → 填自己的访问密钥 → 保存”为主；地址、模型和性能参数收在高级设置中。未连接 AI 时仍可导入和阅读文件。扩展首次安装会打开设置，网页伴读仍通过点击工具栏图标开启；扩展无需桌面后端。当前插件为解压试用包，正式一键安装仍需上架浏览器商店。

仓库包含 [Package Easy Learn 工作流](.github/workflows/package.yml)。将工作流推送到 GitHub 默认分支后，可在 Actions 中选择该工作流并点击 **Run workflow**；推送 `v*` 标签也会触发。Windows 与两种 Mac 使用各自原生 runner 打包并测试，成功后从该次运行的 **Artifacts** 下载 ZIP 与 SHA-256 校验文件。工作流只上传构建产物，不自动发布 Release。构建命令、复用调研、验证范围和签名边界见 [桌面分发记录](docs/desktop-distribution-0.15.md)。

当前为测试包：Windows 尚未完成发行者签名，Mac 原生 CI 只做临时签名校验，正式分发仍需 Developer ID 签名与公证。本地 WSL 生成的 Mac 包尚未在 Mac 执行验证。学习价值主要是减少查词与切换工具、保留原文阅读和提供理解练习；尚未测量真实学习者的长期学习效果，不应宣传保证提分或词汇增长。

## 阅读工作台

阅读交互新增目录标题搜索、“定位当前章节”、顶部章节切换与专注阅读模式；生词本支持按单词/释义搜索并组合语言、学习状态筛选。搜索和视图切换不请求模型，Anki 导出始终包含全部学习中的词汇。支持系统“减少动态效果”偏好，详见 [阅读交互说明](docs/reader-experience-2026-10.md)。

0.14.3 增加 PDF 手形拖动、目录原文高亮闪烁两次、选段解释 / 翻译 / 考考我，以及原版 PDF 的文字高亮、任意位置文字批注、画笔、撤销 / 重做和含批注 PDF 导出。批注留在本次阅读中，关闭或换文件前请导出；原文件不会被覆盖。中文批注可在工作台重开，但受 PDF.js 的字体外观流限制，部分外部阅读器可能不显示。详见 [PDF 交互与编辑说明](docs/pdf-interaction-0.14.3.md)。

0.14.2 增加 PDF 连续阅读、实际大小 / 适合页面 / 适合宽度、缩放滑条及输入页码跳转，并在缩写释义中展示英文全称。详见 [PDF 控制与缩写说明](docs/pdf-controls-0.14.2.md)。

0.14.1 修正了词频基础顺序与低频词筛选，并为 PDF 增加保留图表的原版视图和书签 / 标题层级目录。物理页与章节分别导航；详见 [PDF 阅读修正](docs/pdf-reading-0.14.1.md)。

新增独立文件阅读入口：PDF、EPUB、TXT、Markdown。保留外语原文，按英语常用词基础提前筛选生词，流式准备中文语境释义；可记录已认识的词、收集生词并导出到 Anki。也提供法、德、西、日、韩的基础分词。扩展设置里的“阅读工作台”可以直接打开；无需安装扩展的本机版本：

```sh
pnpm build:workbench
pnpm workbench
```

打开 `http://127.0.0.1:4178`，先连接模型，再导入文件并开启伴读。默认提前处理当前章节和接下来两节，整份预读可自行开启。导入和悬停不发起模型请求。PDF 原版保留图表并叠加生词标注，可切换文字伴读；扫描 PDF 可查看原版，生词分析需先 OCR。其他语言暂时没有词频等级表。

设置新增 DeepSeek 思考模式 / 强度、CPA / OpenAI Fast 优先通道、输出上限、Temperature、1–12 路并发，以及网页常用词基础与生词密度。Fast 是否生效取决于上游账户、模型和代理，不保证 TPS。界面统一系统字体、灰白表面和克制的蓝色强调，支持深色模式。

实现、数据存储边界、开源仓库与用户 issue 调研见 [0.14 工作台说明](docs/reading-workbench-0.14.md)。复用 pdf.js、EPUB.js、fflate、marked、DOMPurify；未复制 GPL / AGPL 产品代码。

## 安装试用

1. 如果已经有本项目的 `dist` 文件夹，可直接安装。重新构建需要 Node.js 22.13+（或 24 LTS）与 pnpm：
   ```sh
   pnpm install --frozen-lockfile
   pnpm build
   ```
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」，选择本项目 **dist** 文件夹。
3. 在扩展详情中打开「扩展程序选项」，可从订阅账户登录、本机与局域网、中国大陆与海外 / 国际服务分组中选择预设，或填写 OpenAI 兼容接口。详细介绍与推荐理由见 [AI 服务商与模型选择](docs/model-providers.md)，免费额度见 [免费方案说明](docs/free-providers.md)。地址如 `https://你的服务商/v1`，插件会补上 `/chat/completions`；也接受已经包含该路径的地址。
4. 点击「保存并授权」，再点击「测试已保存的连接」。本机模型服务可用 `http://localhost:端口/v1` 或 `http://127.0.0.1:端口/v1`；其他服务要求 HTTPS。
5. 打开英文技术文档或博客，点击工具栏里的 Easy Learn 图标即可开始网页伴读。在线文本型 PDF 可从工具栏进入阅读页；本机 PDF 可在阅读页直接选择文件。原生 PDF 中也可选中文字后右键选择「用 Easy Learn 解释 / 翻译选中文字」，结果会显示在浏览器侧栏。

加载后建议将扩展固定到工具栏。浏览器内置页无法注入时，启动状态窗会提供重试、设置和独立的粘贴文本面板入口。更新构建后，在扩展管理页点击重新加载，再刷新已开启伴读的网页。

### 切换服务方案时保留配置

在「服务方案」下拉框切换时，扩展会在本机暂存上一方案的 API Key、地址、模型和解释偏好，包括尚未提交的输入。切换回来会恢复这些内容，重新打开设置页后也可切回恢复；原有的已保存配置自动纳入。修改预设的地址或模型仍保存在该方案下，「自定义服务」有一个独立暂存位置。首次选择未配置的方案时密钥为空，不借用其他方案的密钥。

暂存不请求模型、不更改当前实际连接；只有「保存并授权」后，新配置才生效。重新打开设置页默认显示正在使用的连接。暂存仅存于本机扩展存储，网页无法读取；「清除本机数据」会删除所有方案和密钥。

### ClinePass / DeepSeek 接入

在扩展设置中选择「自定义服务」，填写：

| 设置         | 值                               |
| ------------ | -------------------------------- |
| API Base URL | `https://api.cline.bot/api/v1`   |
| 模型名称     | `cline-pass/deepseek-v4.1-flash` |
| API Key      | 自己的 Cline API Key             |

点击「保存并授权」，再点击「测试已保存的连接」。扩展会补齐 `/chat/completions` 并发送 Bearer 认证，同时兼容 Cline 非流式响应的 `data` 包装。2026-09-30 使用临时凭据、小段公开技术文字验证了项目模型调用代码的非流式解释与流式注释；浏览器回归仍使用本机模拟服务。更新后先重新加载扩展，再刷新文章。

## 订阅账户登录与 ChatGPT Plus

0.13.0 起设置页提供 ChatGPT / Claude 订阅账户 OAuth 入口。**ChatGPT 扩展内 OAuth 仍属实验性**：流程和模拟回调测试已实现，但尚未确认 OpenAI 接受该扩展的回调地址，也未完成真实登录验收，不能保证登录成功。当前本机已验证可用的是下方 CPA 方案；持有 Codex CLI 的 `auth.json` 时，设置页也支持导入到浏览器本机存储。详见 [Plus 接入记录](docs/chatgpt-plus-integration.md)。

若登录回调不被官方支持，或希望沿用原有本机代理，可使用下面的本机 CPA 方案。

### 本机 CPA 代理（个人试用）

本机已通过 CLIProxyAPI 连接当前 ChatGPT Plus 账号的 Codex 通道。该预设使用 GPT-6 Luna；翻译采用无思考强度和精简输出，其他任务采用低思考强度。扩展设置里选择「ChatGPT Plus · 本机 CPA（个人使用）」，将 `.cache/cpa/extension-key` 中的访问密钥填入 API Key，保存授权并测试连接。更新扩展后，先在扩展管理页重新加载。此项是当前本机试用方案，不作为商店上架后的默认连接方式；不需要在扩展里填写 ChatGPT 密码。

代理可用 `python3 scripts/cpa-local.py status` 检查，用 `start` / `stop` 启停。换机首次准备时执行 `python3 scripts/cpa-local.py setup --auth-file <已登录 Codex 的 auth.json 路径> [--proxy-url <本机代理地址>]`，工具会下载并验证固定版本的 CPA，生成本机访问密钥，导入已有登录凭据并启动服务。凭据、密钥、程序和日志都放在 Git 忽略的 `.cache/cpa/`。更多兼容性和发布边界见 [Plus 接入记录](docs/chatgpt-plus-integration.md)。

## 新增：练会这一段（0.10.0）

1. 打开选段解释面板，点击「练会这一段」；也可粘贴文本后选择「先练再看」，先练再看解释。
2. 写下想把这段知识用在哪里（可选），点击「出一道练习题」。AI 根据当前选段出一道开放题，并准备一个应用小任务。
3. 先用自己的话回答，再点击「请 AI 找出理解缺口」。反馈区分理解正确的部分、具体缺口和参考解释；提交前不显示反馈或应用任务。练习中收起原文和解释，可随时返回阅读。
4. 试着完成应用小任务。点击「保存练习，明天复习」后，原文选段、目标、题目、回答、反馈与任务才保存在当前浏览器。
5. 从面板的「我的复习」或设置页的「打开我的复习」进入列表。复习时先回忆，再看第一次的 AI 反馈，自己选择「还需练习」或「能独立解释」。可在「记录实践」写下做法、结果和下一步，并导出 Markdown 学习记录。

成功生成练习和提交反馈通常各请求一次模型；进入练习页、保存、复习、记录实践和导出不请求模型。限流或失败保留输入，只在再次点击时重试。复习不自动评分，也不重新让 AI 判断回答；复习次数和实践记录数不等于掌握程度。

初次保存 24 小时后到期。自评能独立解释后，间隔依次为 3 / 7 / 14 / 30 天，最长 30 天；还需练习则回到 1 天。这是固定的复习建议，不是个性化记忆算法。到期后在「我的复习」显示，不发送系统通知。

## 新增：选段快测（0.11.0）

在普通网页中选中一段文字后，浮动工具条会直接显示「解释」「考考我！」和「翻译」。点击「考考我！」后，AI 根据所选文字出一道四选一题；在选择答案前不展示正确答案，选择后显示对错、参考答案和依据。再次选择「再出一道」会按需请求下一题。

快测请求仅发送主动选中的文字，不附带页面标题、相邻段落或整章；题目和作答不会保存到复习列表。选中 PDF 的操作仍使用浏览器原生右键菜单。面板将「解释」「练会这一段」「考考我！」并列显示，「我的复习」保留为顶层入口；应用任务仍在开放题作答并获得反馈后出现。

## 新增：整页测验、PDF 伴读与订阅直连（0.13.0）

- **整页测验**：网页右下角新增「整页测验」开关。点击后扩展抽取正文，按设置的题数（默认 5，可在设置中调为 3 / 5 / 8）出若干道四选一题。先作答再显示原文引用，提前查看原文会记为开卷。成绩只统计本轮选择，不代表掌握。长文会抽样，不能保证覆盖所有章节。
- **文本型 PDF 伴读**：在线 PDF 可从工具栏进入阅读页，本机 PDF 可直接选择文件；扩展用内置 pdf.js 在浏览器中提取文字。可按 PDF 自带目录或页码定位，打开在线 PDF 的对应原始页面核对图表和排版。选中难句后先用自己的话解释并获取原文反馈，也可直接解释或翻译；另有按页学习与跨页抽样测验。理解核对在提交回答后才请求模型，不自动保存。AI 反馈的短引文会在本地与所选原文核对，文字匹配不代表论断正确。扫描版 PDF 无文字层，仍不支持。
- **订阅入口与更多服务商**：新增 ChatGPT / Claude 订阅 OAuth 入口，其中 ChatGPT 扩展回调仍待真实验证；预设扩展到 23 个，覆盖 Anthropic 官方 Messages 协议、Ollama / LM Studio / vLLM 本机运行时、硅基流动、火山方舟、混元、Mistral、xAI、Together 等；其中 Cline（ClinePass）是独立预设：官方网关的非流式响应带 `{success, data}` 包装，扩展自动拆包并读取用量，流式为标准 OpenAI 事件。
- **更多自定义**：设置页新增每段注释上限（2 / 4 / 6）、每批请求数（2 / 4 / 6 / 8）、解释风格（简洁 / 平衡 / 深入）与整页测验题数。

## AI 服务商与模型选择（0.12.0）

设置页现按「中国大陆服务」和「海外 / 国际服务」分组，加入阿里云百炼 Qwen3.8 Flash、OpenAI GPT-4.1 mini、Google Gemini 3.8 Flash 和 Kimi K2.6 等预设，同时保留 DeepSeek、智谱及原有国际选项。千问预设会提示从百炼控制台复制业务空间 API Host；扩展会按该接口要求发送非思考模式和输出上限参数。服务商、接口地区和模型可能变化；完整清单、隐私 / 计费提醒与推荐依据见 [模型选择说明](docs/model-providers.md)。

## 使用方式

- 当前页面每个概念的首次标注使用浅蓝色背景与实线下划线；同一含义后续出现时改用淡色点线，减少重复强调。悬停立即显示已经预载的短注释，不发起模型请求；原文和链接保持不变。
- 常见软件技术词和已支持的命令使用内置通用释义，即刻标注，零 API 请求。通用词典不强行消歧 DR 等缩写；需要上下文判断时再发送给模型。设置中的“离线模式”可完全停止新的 AI 请求。
- 本地规则先筛选明确的技术词和缩写；普通词、常见标题、通用变量名默认跳过。每段通常最多六个候选；可选的「扩展词汇」实验模式每段默认最多再加一个，可调为 1–6 个。HTTP 方法结合 Web 语境判断，避免标记普通 get/post 动词。漏掉的内容仍可划词解释。
- 开启后立即扫描整页，每批默认 8 个候选，携带各自最多 420 字符的语境片段；每批重新排序，优先当前屏幕、接下来两屏及后续正文，最后处理已读位置；默认六路并发自动处理全文（可调 1–12 路），不以滚动为触发条件。同一语境复用缓存，动态加载的新正文自动补充。限流或认证失败时暂停，已有注释仍可阅读。
- 整页自动预载，不再设旧版八批停止线。右下角常驻浮窗显示进度，悬停约半秒展开注释类型、代码开关、偏好、暂停和错误详情。全文预载可能比仅处理视口消耗更多额度；主动翻译/追问/连接测试也会产生请求。实际费用由服务商定价决定。
- CLI 命令与代码注释各有开关；两者都在「注释类型」下，命令说明独立于默认关闭的代码注释。除常见 FastAPI 教程命令外，还会识别 `sed`、`grep`、`awk` 等常见 shell 工具。对 Linux、WSL 和 PowerShell 提示符会剥离提示符，仅把命令本身送去解释；带提示符的命令输出不会当代码分析。解释不执行命令。
- 代码注释默认关闭；在网页浮窗或扩展设置页的「注释类型」中开启。命令行类型开关独立生效。开启代码后按最多八行分块，预载逐行解释及组成片段。
- 网页中选中一段文字后，浮动工具条提供「解释」「考考我！」和「翻译」三个入口。快测只发送主动选中的文字，答案在作答前隐藏；原文不替换，也不添加包装节点。
- 原生 PDF 中选中文字后，右键选择「用 Easy Learn 解释选中文字」或「用 Easy Learn 翻译选中文字」，结果在侧栏显示。只有主动选中的文字和文档标题会发送给模型；过长选区限制为 16,000 字符并明确提示。
- 在 PDF 页点击工具栏图标可选择「用 Easy Learn 阅读此 PDF」，或在阅读页直接选择本机 PDF。提取在本机完成，仅主动使用的选段或测验样本会发送给模型服务。本机文件最多 100 MB；`file://` 地址请改用文件选择入口。扫描版 PDF 无文字层，无法提取。
- 悬停注释中的「深入理解 / 翻译」才会打开右侧面板并按需请求详细解释。预载注释与主动追问是两种不同操作。
- 「翻译这一段」保留原文；「加入当前章节」明确扩大模型输入范围；「继续追问」带上当前会话的最近对话。
- 悬停注解中点击“我懂了，不再显示”即可隐藏这一含义的注解，设置页的“不再显示”列表可恢复；以领域和概念含义区分，不混淆同一缩写的不同含义。此操作只是显示偏好，不评估掌握程度。
- 点击浏览器工具栏图标会立即尝试开启当前页面；状态窗会在成功后自动关闭，遇到无法注入的页面时提供重试和粘贴文本入口。右下角的常驻「阅读注释」浮窗提供进度、类型选择、暂停、粘贴文本和设置入口。鼠标悬停片刻后展开详细设置。

## 数据与权限

- 扩展使用 `activeTab`、`scripting`、`storage`、`contextMenus`、`sidePanel` 和 `identity` 权限；不会预先读取网页或整份 PDF。模型地址与 PDF 所在站点作为可选权限，在保存配置或提取的点击操作中申请；订阅登录会申请官方登录站点与对应接口域名的权限。
- API Key、订阅 OAuth 令牌和偏好存在 `chrome.storage.local`，仅扩展可信界面与后台能访问；不使用同步存储。订阅令牌到期前由后台自动刷新，「清除本机数据」会一并删除。它不是操作系统保险库，不应把扩展配置目录交给他人。
- 自动预载发送页面标题和本地筛选候选的短语境；主动深入解释、翻译和开放式练习会发送章节标题、目标段落及相邻段落。网页快测只发送用户选中的文字；点击全文翻译后，识别出的正文会分段发送，排除导航、编辑框、代码块及隐藏内容。首次配置页明确说明发送行为和可能的费用。扩展本身不运行任何分析或遥测服务。
- 学习练习只在点击保存后写入 `chrome.storage.local`，最多 50 条且总量不超过 2 MB（UTF-8 JSON）。保存当前选段、标题、目标、题目、第一次回答与 AI 反馈、应用任务、最近一次回忆、实践记录和复习日期，不保存邻段、整章、网页地址或密钥。记录不自动过期，可逐条删除或从设置页清除全部本机数据；达到上限时拒绝新增，保留已有记录。导出的文件由用户自行保管。
- PDF 右键操作只把用户主动选中的文本与文档标题发给已配置的模型服务。选区暂存于 `chrome.storage.session`，侧栏读取后立即删除；关闭标签页也会清除未读取的选区。
- 默认单个段落最多 16,000 字符，相邻段落各最多 4,000 字符；主动扩大后章节最多 24,000 字符。超长段落不自动分析，可选取片段手动处理。
- 未主动保存的正文和问答仅驻留会话内存；关闭网页、停止伴读、重载页面或后台休眠会清除会话内容。默认在本机保存最多 500 条术语/缩写释义，30 天过期，并限制总大小；开启扩展词汇时也会缓存词汇解释。术语缓存不持久保存整段语境、命令或代码。释义本身可能含原文短语，语境仅以哈希参与缓存匹配。模型、领域、熟悉程度、标题与语境一致才复用；不按缩写字面跨语境复用。设置页可关闭并清除缓存，也可单独清除。模型供应商的日志保留方式由该供应商控制。
- 密钥不交给页面脚本，不写日志；模型文本按纯文本显示。网页和用户文本不会拼接进系统指令。仍需自行判断 AI 解释是否准确。
- 后台默认六个模型请求并发，可调 1–12 路，自动预载遵守所选上限；主动解释与翻译优先于排队中的预载，不打断在途请求。自动注释使用流式返回，完整条目验证后立即标注；服务商返回普通 JSON 时仍可读取。首次有效内容等待最多 25 秒，开始输出后连续 12 秒没有内容即中止，总时长最多 60 秒；其他操作仍为 25 秒。流式中断保留已完成条目，未完成项手动重试。兼容 JSON 围栏、简化字段、编号文本和部分有效结果；格式异常只在本地解析，不自动付费修复，未完成项由用户手动重试。
- 伴读开启期间，每 20 秒发送一次扩展内部消息维持后台连接，不调用模型、不产生 API 费用；关闭后停止。

## 开发与验证

```sh
pnpm install --frozen-lockfile
pnpm lint          # 检查 JS/TS 和 React Hooks；新增告警会阻断检查
pnpm format        # 统一 JS/TS、CSS、HTML、JSON、YAML 和 Markdown 的格式
pnpm verify        # lint、格式检查、单元测试、扩展构建、工作台构建
# 使用项目内缓存，无需写入系统的浏览器缓存目录
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm exec playwright install chromium
PLAYWRIGHT_BROWSERS_PATH="$PWD/.cache/ms-playwright" pnpm test:e2e
```

Go 使用 `go vet` / `gofmt`，Python 使用固定版本的 Ruff。安装步骤、各语言命令与历史告警迁移方法见 [代码质量指南](docs/code-quality.md)。推送和 PR 会运行质量检查及浏览器测试，打包流程也会先检查 JS/TS 和代码格式。

单元测试检查正文过滤、上下文边界、原文锚点、缓存、并发及模型错误。端到端测试使用真实 Chromium 扩展与本机模拟模型 API，不发送真实文章给外部服务。测试专用扩展副本临时加入本机测试站点权限，用来程序化触发注入；生产 manifest 不含该权限。

- `src/core`：独立的文本接口、模型适配、校验和内存缓存。
- `src/background.ts`：权限边界、设置、模型调用与页面/面板通信。
- `src/content`：正文提取、全文预载、无损高亮和选择操作。
- `src/ui`：React 阅读面板与设置。
- `docs/acceptance.md`：真实模型和小范围试用验收表。

PDF 伴读已支持文本型 PDF 的整页文字提取、内置目录与页码跳转、本机文件选择和按页学习；长页可展开连续阅读。目录最多读取前 120 项；没有内置书签的文件提供页码跳转。PDF 的扫描版 OCR、图片/公式识别和整篇双语对照仍不支持（网页正文已支持双语对照）。原生 PDF 阅读器内的右键选段解释继续可用。图片、视频、跨域 iframe 和封闭式组件也不支持；终端只分析输入行，跳过日志、进度条和隐藏的重复代码。正文提取依赖常见 `article/main` 与段落结构；不适配的页面可以粘贴文本。语义判断、翻译准确性和学习效果需要真实模型与真实用户检验。
